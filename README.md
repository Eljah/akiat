# Әкият / Akiat — татарские авторские аудиосказки

Открытый набор исходников для экспериментального **некоммерческого** проекта: современные оригинальные татароязычные сказки, редакционный конвейер эмоциональных референсов, распознавание татарской речи (Whisper), разметка обучающего корпуса и синтез голоса (Silero, F5-TTS, Piper).

**Состояние:** прототип. Сценарии озвучки и Colab-блокноты подготовлены, но успешное end-to-end распознавание всех записей и обучение собственного голоса пока **не подтверждены**. MP3, готовые голоса и веса моделей в репозиторий **не входят**.

## Java сервер, API, MCP, расписание и RSS

**Теперь добавлен Java-модуль [`server/`](server/README.md)** (Spring Boot 4.1.1, Maven, Java 17+, Spring AI MCP, H2/JPA). Он отвечает за регистрацию литературных эмоциональных референсов, поиск кандидатов, регулярную генерацию только *черновиков* татарских сказок, проверку текстов, очередь TTS, контроль прав и выпуск RSS для Яндекс Музыки. Python-воркер находится в [`worker/silero_api_worker.py`](worker/silero_api_worker.py).

По умолчанию сетевые административные интерфейсы доступны только с `127.0.0.1`; требуется задать `AKIAT_ADMIN_PASSWORD`. Для автоматического генератора нужны отдельные ключи LLM, запуск автоматической генерации по расписанию по умолчанию выключен. Публикация невозможна без подтверждения языковой проверки, аудио и прав. MCP Streamable HTTP — `/mcp`, c отдельным токеном через `AKIAT_MCP_TOKEN`. Подробности: [server/README.md](server/README.md).

```bash
export AKIAT_ADMIN_PASSWORD='replace-with-strong-password'
mvn -f server/pom.xml clean verify
mvn -f server/pom.xml spring-boot:run
```

RSS: `http://127.0.0.1:8080/feed.xml` (для Яндекса требуется публичный HTTPS и первый одобренный выпуск). См. [правила размещения Яндекс Музыки](https://yandex.com/support/music-artists/ru/podcast-authors/audio-placement): первоначальная заявка ручная, затем обновления подкастов принимаются через RSS. Приём именно авторских аудиосказок нужно подтвердить модерацией.

## Запуск: Whisper в Google Colab

Актуальная версия: **[notebooks/00_START_HERE_Whisper_Tatar_v4.ipynb](notebooks/00_START_HERE_Whisper_Tatar_v4.ipynb)** — [открыть в Colab](https://colab.research.google.com/github/Eljah/akiat/blob/main/notebooks/00_START_HERE_Whisper_Tatar_v4.ipynb).

1. В Colab выбрать `Runtime → Change runtime type → T4 GPU`.
2. В Google Drive создать `MyDrive/tatar_audio_lab/raw_mp3/` и разместить **свои / разрешённые** записи. Блокнот специально поддерживает реконструкцию большого файла из `podcast_part01.mp3` и `podcast_part02.mp3` (при наличии этих файлов).
3. Выполнить `Runtime → Run all` и разрешить доступ к Google Drive.
4. Начать с `SMOKE_TEST=True`: блокнот сначала проверяет модель и распознаёт небольшие фрагменты.
5. Проверить промежуточные файлы в `MyDrive/tatar_audio_lab/asr/`. В случае ошибки читать `last_error.txt`.
6. После успешного теста поставить `SMOKE_TEST=False`, заново выполнить все ячейки для полного корпуса. Готовые части пропускаются при повторном запуске.
7. Проверить транскрипции и интервалы вручную. **Whisper не удостоверяет личность говорящего; результат не готов для TTS без вычитки**.

В версиях v3/v4 исправлялись известные несовместимости токенизатора и `eos_token_id` для word timestamps. GPU-конфигурации Colab и модели Hugging Face со временем меняются, поэтому `v4` не является гарантированно стабильным на любой версии среды.

## Генерация пробных татарских сказок через Silero

Из корня репозитория (потребуются Python, PyTorch, NumPy, интернет для загрузки модели и при экспорте MP3 — ffmpeg):

```bash
pip install torch numpy
python silero_render.py --stories stories --max-sentences 8 --mp3
python silero_render.py --stories stories --mp3
```

По умолчанию проверяются татарские голоса модели `v5_cis_ext`. Вариант `v5_turkic` поддерживается через `--model-id v5_turkic --voices tat_0`. Синтезированные WAV/MP3 пишутся в `outputs/` (игнорируется Git). Произношение нужно проверять на слух; модели/данные третьих сторон имеют самостоятельные лицензии, не заменяемые лицензией проекта.

## Сборка собственного речевого корпуса

- `notebooks/01_Whisper_Tatar_Corpus.ipynb`: исходный сценарий (исторический).
- `notebooks/00_START_HERE_Whisper_Tatar_v3.ipynb`: предыдущая отладочная версия.
- `notebooks/00_START_HERE_Whisper_Tatar_v4.ipynb`: актуальный запуск Whisper.
- `notebooks/01_Whisper_Tatar_Corpus_FIXED.ipynb`: историческая попытка исправления.
- `training/srt_to_segments.py`: черновой SRT → CSV.
- `training/prepare_father_dataset.py`: разметка подтверждённых фрагментов → WAV 22.05 кГц + `metadata.csv` в формате Piper.
- `notebooks/02_F5_Tatar_Voice_Reference.ipynb`: эксперимент F5-TTS с разрешённым голосовым образцом.
- `notebooks/03_Piper_Tatar_Finetune_Experimental.ipynb`: экспериментальная адаптация модели Piper.
- `notebooks/04_Silero_Tatar_3x3.ipynb`: сравнение голосов для трёх историй.

Остальные каталоги: `stories/` (3 оригинальных литературных черновика), `catalogue/` (120 концептов), `resources/` (эмоциональные ориентиры и шаблон словаря ударений), `docs/` (редакционный и технический планы), `tools/history/` (исторические скрипты создания блокнотов с локальными путями для разработки).

## Авторские права, согласие, безопасность

* Для **выпуска** синтетического голоса нужны необходимые разрешения записанного человека и права на используемые фонограммы/исполнения. Это важно и для некоммерческого проекта. Не обучайте узнаваемый голос актёра без согласия и не публикуйте чужие записи.
* Произведения современных авторов используются как **эмоциональные референсы**, а не как тексты для близкого пересказа. Идеи, эмоциональный тон и общие жанровые свойства отличаем от оригинальной художественной конструкции.
* Не коммитьте собственные интервью, ASR-результаты, speaker embeddings, checkpoint-файлы, токены и данные участников. `.gitignore` защищает от типовых ошибок, но не заменяет проверки `git status` перед публикацией.
* Примеры текстов сгенерированы специально для этого проекта и требуют редакторской татароязычной вычитки перед публикацией.

## Качество и CI

В репозитории имеется статический валидатор `tools/validate_notebooks.py`, проверяющий JSON-формат, синтаксис Python-ячеек и отсутствие сохранённых результатов/токенов. GitHub Actions не запускает Whisper, F5-TTS или Piper и не расходует GPU.

**Лицензии:** сторонние ASR/TTS-модели и обучающие материалы имеют собственные условия; репозиторий не предоставляет прав на них и на чужие записи. Новая лицензия к содержимому пользовательского репозитория автоматически не назначается.
