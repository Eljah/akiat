# Татарские аудиосказки: эмоциональные референсы → собственный текст → Silero/Piper

Состояние проекта на 20 октября 2026: три ранее написанных **текстовых** татарских черновика, три источника-референса по издательским описаниям, скрипты для генерации нескольких вариантов озвучки и подготовки обучающих данных голоса. В этом архиве **нет готовых MP3/WAV от Silero**: сетевой доступ к весам модели в рабочей среде отсутствовал. Ни одна модель не была обучена на голосе отца, поскольку исходная запись не предоставлена.

## 1. Что мы делаем, а чего не делаем

- Поиск: современная авторская русская детская сказка, автор, название, описание и легальный источник для чтения.
- Анализ: без копирования выражения фиксируются абстрактные особенности **эмоционального переживания**: неловкость, уют, детская нелогичность, безопасность, юмор, тревога, любопытство, неспешность.
- Проектирование: сознательно заменяем не только декорации, имена и предметы, но и **неповторимую цепь действий**, оригинальный механизм чуда, комические находки и причинные развязки. Новая история должна быть независимой от оригинала, не «переименованным пересказом».
- Редактор: татарский текст создаётся как самостоятельный литературный текст. Носитель вычитывает идиомы, синтаксис, динамику диалогов.
- Публикация: указывается эмоциональный ориентир в рабочем реестре, но он не превращается в ложное авторство, перевод или аффилированное произведение.

Юридическая основа: п. 5 ст. 1259 ГК РФ исключает охрану **идей и концепций** как таковых, но это **не** разрешение воспроизводить оригинальный сюжет, образы и выражение. Некоммерческий характер записи не снимает автоматически охрану исходного произведения. Отдельно нужно проверить режим распространения полученных аудиофайлов и лицензию Silero, если запись будет опубликована на коммерческой платформе.

Проверенные отправные точки: 
- Сергей Седов, «Сказки про мам»: https://www.labirint.ru/news/2475/
- Андрей Усачёв, «Умная собачка Соня»: https://ast.ru/book/umnaya-sobachka-sonya-077604/
- Елена Ракитина, «Приключения новогодних игрушек»: https://rech-deti.ru/catalog/7/179/
- Реестр: `resources/emotional_references.csv`.

Важная точность: наши первые три татарские истории появились **до** отбора этих референсов. Привязка в реестре — ретроспективное сопоставление эмоциональных регистров, **не** результат анализа полных оригиналов и последующей адаптации. Для следующих историй использовать заданный ниже процесс последовательно.

## 2. Протокол «эмоционального отпечатка»

Для каждой исходной сказки составить JSON-карточку (только после легального знакомства с произведением):

```json
{
  "reference": {"author": "...", "title": "...", "source_url": "..."},
  "age": "5-7",
  "feeling_at_start": ["любопытство", "маленькое неудобство"],
  "feeling_in_middle": ["смешная неловкость", "сочувствие"],
  "feeling_at_end": ["облегчение", "тёплая незавершённость"],
  "humor_mode": "мягкое буквальное понимание",
  "adult_role": "не морализирует",
  "explanation_level": "низкий",
  "pace": "два коротких ускорения и паузы",
  "avoid_from_source": ["персонажи", "сцены", "дословные обороты", "оригинальный волшебный механизм", "фирменные шутки", "причинно-событийная цепь"],
  "new_plot_candidates": ["новая независимая фабула А", "Б", "В"],
  "language": "Татарский, живой литературный, самостоятельная художественная речь"
}
```

**Промпт для нового сценария**:

> Возьми только эмоциональный отпечаток (эмоциональная траектория, плотность юмора, отношение к детской ошибке, уровень созерцания и мягкость финала), НЕ используй сюжетную канву, имена, оригинальные образы, особые предметы, шутки и текст источника. Сначала придумай три принципиально различные татарские фабулы, отбрасывая сюжетное сходство с источником. Затем напиши самостоятельную татарскую сказку для указанного возраста, с естественными диалогами, без прямой морали и без этнографической обязаловки. Не называй её переводом или пересказом. Проверь, что идея понятна ребёнку, который понимает татарский, но пока мало говорит на нём.

## 3. Синтез нескольких татарских голосов Silero

Официальные ссылки:
- https://github.com/snakers4/silero-models
- https://github.com/snakers4/silero-models/blob/master/models.yml
- https://github.com/snakers4/silero-models/wiki/SSML

Модель `v5_cis_ext` доступна через `torch.hub.load(..., language='ru', speaker='v5_cis_ext')`. `ru` здесь — ключ семейства моделей в репозитории, а сами татарские голоса выбираются ID `tat_*`. **Не** используйте `language='tt'` для этой группы.

В официальном описании перечислены 19 татарских голосов, включая `tat_alsou`, `tat_bulat`, `tat_zifa`. По умолчанию генерируются все три сказки каждым из этих трёх голосов (3×3=9 вариантов). Можно выбрать другие голоса флагом `--voices`.

Установите Python 3.10–3.12, PyTorch, NumPy и FFmpeg. Для Windows можно использовать WSL2. В Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch numpy omegaconf
sudo apt-get install ffmpeg

# Короткое прослушивание первых 8 предложений каждой истории:
python silero_render.py --max-sentences 8 --mp3

# Полные сказки, 3 различных голоса:
python silero_render.py --mp3

# Сравнение четырёх других голосов на коротком отрывке:
python silero_render.py --voices tat_adiba tat_karim tat_mansur tat_rasima --max-sentences 12 --mp3

# Вариант без необходимости вручную отмечать ударения (1 татарский голос):
python silero_render.py --model-id v5_turkic --voices tat_0 --max-sentences 12 --mp3
```

Файлы создаются в `outputs/`, с суффиксом конкретного голоса. Впервые при выполнении скрипт скачает модель через официальный PyTorch Hub. Требуется интернет. Для самостоятельного запуска без установки есть `notebooks/Silero_Tatar_3x3.ipynb`, который открывается в Google Colab и содержит тексты внутри.

**Об ударениях:** `v5_turkic` с голосом `tat_0` — удобный контрольный вариант, поскольку не требует указания ударений, но предлагает лишь один татарский голос. Официальная документация `v5_cis_ext` требует расстановки ударений через `+`; эта версия не расставляет их автоматически даже по-татарски. Скрипт запускает базовый (неразмеченный) текст для сравнения голосов, но для публикации нужен словарь `resources/stress_lexicon_TEMPLATE.tsv`, в котором носитель татарского проверил расстановку. Подключение: `--lexicon resources/stress_lexicon.tsv`. Без такой правки звучание может быть заметно хуже. Скорость речи и паузы регулировать прежде всего сегментацией и SSML после слуховой проверки.

Лицензия v5_cis_ext в официальном README указана как `CC-NC-BY`, с некоммерческим ограничением и атрибуцией. Даже если создатели проекта не получают деньги, включение на коммерческой платформе может потребовать отдельного правового анализа условий модели; при сомнении написать на hello@silero.ai.

## 4. Интервью отца: от аудиозаписи до датасета

1. Получите прямое согласие на создание синтетического голоса и дальнейшую публикацию, убедитесь, что отец понимает возможные применения. Если есть посторонние голоса, удалите их сегменты.
2. Для распознавания татарского попробуйте модель `JackGauter/whisper-small-tt-ggml` или `yasalma/whisper-finetuned-tt-asr`. Это только *черновая* расшифровка, на интервью с шумом/смешением языков будут ошибки.
3. Полный файл конвертировать в mono PCM16 WAV 16 кГц для ASR. Записать временные границы в SRT, затем сконвертировать в CSV командой `python training/srt_to_segments.py draft.srt training/segments_review.csv`.
4. Ручная редактура CSV: удалить собеседника, паузы и пересечения, исправить слова/окончания, совпадение аудио и текста. **Не редактировать сказанное «литературно»**, иначе ASR/TTS пары будут не совпадать. Сегменты 1.2–14 с, лучше 3–10 с, в среднем 3–8 с.
5. `python training/prepare_father_dataset.py --audio father_interview.mp3 --segments training/segments_review.csv --output training/father_ljspeech`.
6. Прослушать WAV сегментов ещё раз; плохие пометить и исключить. Получается `metadata.csv` формата `id|text`, `wav/id.wav`, плюс отчёт.
7. Отложить последние 5–10% **независимых** сегментов в тестовую выборку (скрипт создаёт единый корпус; разнести обучающую и тестовую части следует самостоятельно до обучения).

Пример подготовки аудио:

```bash
ffmpeg -i father_interview.mp3 -ac 1 -ar 16000 -c:a pcm_s16le father_16k.wav
```

Черновая татарская ASR-модель через whisper.cpp:

```bash
# Установка whisper.cpp зависит от вашей ОС; далее пример Linux/WSL2:
git clone https://github.com/ggml-org/whisper.cpp
cd whisper.cpp
cmake -S . -B build
cmake --build build --config Release -j 4
python -m pip install huggingface_hub
hf download JackGauter/whisper-small-tt-ggml ggml-tt-small-q4_0.bin --local-dir models
./build/bin/whisper-cli -m models/ggml-tt-small-q4_0.bin -l tt -f ../father_16k.wav -osrt -of ../father_draft
cd ..
python training/srt_to_segments.py father_draft.srt training/segments_review.csv
```

ASR может неверно узнавать разговорную речь, особенно русские вкрапления; редактирование человеком обязательно. Стандартизация аудио (22050 Гц) происходит при создании датасета. Само интервью не нужно публиковать в репозитории.

## 5. Дообучение Piper на отцовском голосе

Основной путь: официальный проект TatarTTS (`IS2AI/TatarTTS`) обучен через `rhasspy/piper`; доступны `.ckpt` для мужчин и женщин. Скачайте мужской **training checkpoint** из ссылки авторов (не путайте с inference `.onnx`). При использовании старой тренировки PyTorch Lightning учитывайте совместимость версии.

Общий алгоритм (исходный Piper; на реальном GPU не исполнялся):

```bash
# внутри piper/src/python в окружении, установленном по README IS2AI/TatarTTS
python3 -m piper_train.preprocess \
  --language tt \
  --input-dir /absolute/path/to/father_ljspeech \
  --output-dir /absolute/path/to/father_processed \
  --dataset-format ljspeech \
  --single-speaker \
  --sample-rate 22050

# male.ckpt: контрольная точка той же архитектуры и частоты 22050
python3 -m piper_train \
  --dataset-dir /absolute/path/to/father_processed \
  --accelerator gpu \
  --devices 1 \
  --batch-size 8 \
  --validation-split 0.05 \
  --num-test-examples 0 \
  --max_epochs 200 \
  --checkpoint-epochs 5 \
  --precision 32 \
  --resume_from_checkpoint /absolute/path/to/tatar_male_pretrained.ckpt

python3 -m piper_train.export_onnx \
  /absolute/path/to/new_father_voice.ckpt \
  /absolute/path/to/father_tatar.onnx
```

Затем сохранить соответствующий `config.json`, проверить совместимость фонемного словаря, сгенерировать фиксированные 10 тестовых татарских фраз и выбрать лучшую контрольную точку по слуху. Не запускать обучение вслепую до конца 200 эпох: малая выборка может быстро переобучаться.

**Ограничения:** 30 минут *чистой* одноголосой речи — минимальный пилот, не гарантия качества. Для устойчивого совпадения голоса и выразительного чтения лучше дополнительно записать 30–60 минут **читанной** татарской речи с разнообразием звуков, интонаций и окончания предложений. Если отец говорил на интервью только по-русски, начать с нескольких новых татарских читаемых отрывков особенно важно.

- https://github.com/rhasspy/piper/blob/master/TRAINING.md
- https://huggingface.co/JackGauter/whisper-small-tt-ggml

## 6. Контроль качества

Для каждого произведения фиксировать 1–5 баллов по: произношению, естественности татарских окончаний, интонационной выразительности, темпу и паузам, эмоциональной интонации и желанию ребёнка слушать дальше. Выбрать 2–3 голоса и сделать слепое сравнение 8–12 фраз разных жанров. Статус "готов к публикации" только после вычитки носителем и прослушивания всего MP3. Не забывать авторскую атрибуцию для лицензируемых компонентов аудио.
