# «Әкиятләр дөньясы» — редакционный и технологический план

**Дата подготовки:** 20 октября 2026 года  
**Состояние:** 120 оригинальных сюжетных концептов; 3 первых текстовых черновика на татарском; аудиофайлы пока не изготовлены, публикации и модерации ещё не было.

## 1. Цель проекта

Создать долгоживущий каталог татароязычных современных детских аудиоисторий, сопоставимый по эмоциональному и жанровому разнообразию с русскоязычной средой детских аудиосказок. Не делать основной целью обучение языку, воспитательное сообщение или пересказ фольклора. Цель — истории, которые ребёнок захочет слушать снова.

## 2. Из чего состоит первый пакет

- `tatar_audio_tales_120_editorial_plan.xlsx`: полный журнал 120 сюжетов, обзор 12 жанров, редакционная политика, этапы и тесты Алисы;
- `120_tatar_audio_fairy_tales_catalogue.csv`: машиночитаемый каталог;
- `pilot_01_ostal_astyndagy_dingez.md`: «Өстәл астындагы диңгез» (уютное бытовое волшебство);
- `pilot_02_buleshase_kilmagan_kon.md`: «Бүлешәсе килмәгән көн» (отношения без назидательности);
- `pilot_03_kanikulga_kitkan_chainik.md`: «Каникулга киткән чәйнек» (бытовой абсурд).

**Важное ограничение:** тексты — авторские черновики, подготовленные с участием ИИ. Они не проходили редактуру профессиональным татароязычным автором и тестовое детское прослушивание. Их нельзя без вычитки считать законченными литературными текстами.

## 3. Матрица жанров

Двенадцать направлений по десять сюжетов: сонные, абсурд, бытовое волшебство, приключения, дружба и границы, страхи и смелость, семья, город и техника, животные, детективы, негромкая фантастика, созерцательная лирика.

Плановое звучание 120 историй — около **12 часов 39 минут** при выбранных возрастных длительностях 4, 6 и 9 минут. Это целевой план, а не подсчёт готовой озвучки.

## 4. Педагогическая и языковая концепция

### Что должно быть

1. Событие — маленькое, конкретное, интересное с первых 20–40 секунд.
2. Герой — с собственным, иногда неразумным взглядом на мир.
3. Тон — доброжелательный, ироничный, не наставнический.
4. Чувства — сложные, но безопасно предъявленные: досада, ревность, растерянность, стеснение, тихая радость.
5. Финал — наблюдение, смех, перемена настроения или открытый вопрос.
6. Татарский — художественный язык повествования, а не объект методического обучения.

### Чего избегаем

- фраз вроде «шул көннән башлап ул аңлады...» в качестве обязательного морального вывода;
- навязчивой этнографии, чрезмерной архаики и разъяснений традиций;
- синтаксических калек с русского и искусственной литературной торжественности;
- психологических терминов в речи дошкольников без драматургической необходимости;
- ситуаций, где отрицательная эмоция героя автоматически становится «неправильным поведением»;
- оммажей, слишком близких к защищённым сюжетам и персонажам других авторов.

### Языковые ступени

- **T1** (ориентир 3–5 лет, в том числе пассивное понимание): короткие предложения, знакомые глаголы, диалог и ритмические повторы; не «татарский для чайников».
- **T2** (5–7 лет): естественная повседневная татарская речь, узнаваемый городской и семейный контекст, простая метафора.
- **T3** (7–9 лет): самостоятельная интрига, ирония, эмоциональные полутени, выразительные образы и более богатая лексика.

Ступени — не строгие возрастные ограничения. Они относятся к сложности текста и должны оцениваться на слушателях.

## 5. Производственная цепочка

`synopsis → plot-beats → draft_tt → developmental_edit → native_language_edit → child_listening_test → rights_review → casting/TTS → voice_recording → editing → audio_QC → metadata → RSS/distributor → Yandex moderation → Alice QA`

### Gate A — сценарная заявка

В каталоге у каждого рассказа должен быть свой сюжетный механизм, настроение, финальное послевкусие. До написания полного текста необходимо проверить пересечение со всеми уже утверждёнными заявками: одинаковый волшебный предмет допустим, одинаковая логика развязки — нежелательна.

### Gate B — литературный выпуск

Два татароязычных читателя, один из которых профессионально занимается текстом, проверяют: морфологию, разговорность, синтаксис, лексическую уместность, интонационную читаемость, возрастную доступность. Автор утверждает финал без обязательной морали.

### Gate C — детский пилот

С разрешения родителей 3–5 детей соответствующего уровня слушают сказку. Наблюдать: дослушивают ли, что пересказывают своими словами, просят ли включить повторно, какие слова просят объяснить. Не собирать персональные данные детей без отдельной необходимости.

### Gate D — аудио

Сохранять чистый WAV-мастер с достаточным качеством, а публикационный файл создавать отдельно. Для RSS Яндекс допускает MP3 и ряд других форматов, минимальный битрейт 40 кбит/с, рекомендуемый — от 192 кбит/с. Это сведения из официальных требований, а не гарантии принятия.

Не ставить музыку непрерывно под чтением; эффекты допустимы, когда усиливают событие. При чрезмерной фоновой музыке детская речь теряет разборчивость, особенно на небольшой колонке.

### Gate E — права и соответствие платформе

Держать подтверждение прав на сценарий, художественную редактуру, запись голоса, музыку и звуки. Зафиксировать степень применения ИИ и передавать корректную маркировку в том формате, который требуется площадкой/дистрибьютором. Не имитировать известные голоса и не заливать сериями сотни почти одинаковых записей — у Яндекса есть правила против контентного спама.

### Gate F — голосовое обнаружение

Факт появления в Яндекс Музыке **не равен** успеху задачи. Проверять отдельно:

1. Наличие выпуска по прямой ссылке.
2. Появление в детском каталоге.
3. Поиск названия руками.
4. Голосовая команда с русским произношением бренда.
5. Голосовая команда с татарским произношением заглавия.
6. Детский профиль и ограничение «Для малышей».
7. Продолжение и повтор воспроизведения.

В листе `Алиса QA` создана тестовая матрица из десяти запросов. Названия в ней пока рабочие, их нужно согласовать с выбранным названием подкаста.

## 6. Каналы дистрибуции

**Первый маршрут:** HTTPS-хостинг MP3 + валидный RSS-подкаст, затем форма размещения Яндекс Музыки. Отдельно выяснить допустимость законченных художественных сказок в качестве разговорного подкаста.

**Второй маршрут:** сборники через правообладателя/аудиокнижного дистрибьютора. Это другой путь модерации и доступа; не смешивать автоматически права на аудиокниги и права на подкаст.

**Третий маршрут:** навык Яндекс Диалогов для особых сценариев выбора, если он технически поддержит нужное воспроизведение на целевых устройствах. Не предполагать, что сторонний навык автоматически получает доступ к каталогу Яндекс Музыки.

## 7. Рекомендуемый пакет метаданных

```yaml
id: E030
language: tt
language_level: T2
title_tt: "Өстәл астындагы диңгез"
title_ru_guide: "Море под столом"
show_title_tt: "Әкиятләр дөньясы"
age_range: "5-7"
duration_target_seconds: 360
moods: [уют, любопытство, бытовая магия]
author_status: ai_assisted_draft
editor_native_review: pending
narrator: pending
rights_status: pending
script_version: draft-v0.1
audio_master_sha256: null
rss_guid: null
yandex_url: null
alice_qa_status: not_tested
```

При подготовке RSS использовать стабильный GUID, абсолютные HTTPS enclosure URL на MP3, корректные размеры в байтах и уникальные заголовки выпусков. Для продакшена лучше хранить метаданные в Git и генерировать RSS по CI.

## 8. Архитектура небольшого проекта Java/Maven

```text
fairytale-studio/
  pom.xml
  stories/
    E001/
      story.tt.md
      metadata.yaml
      editorial-notes.md
    E002/
  audio/
    masters/             # WAV, вне публичного сервера
    published/           # MP3
  service/
    catalog/             # каталог, переходы статусов, проверки заполненности
    rights/              # подтверждение прав/происхождения
    media/               # информация о публикационных MP3
    rss/                 # генерация RSS 2.0
    publication/         # фиксация URL и версии выпуска
    alice-qa/            # тестовые прогоны голоса и ручная отметка
  web/
    editorial-dashboard/
  .github/workflows/
    validate.yml
    publish-rss.yml
```

Стек: Java 17+, Maven, Spring Boot для редакционного веб-интерфейса, Jackson YAML для метаданных, `ffprobe`/`ffmpeg` для валидации MP3, GitHub Actions для сборки и публикации RSS. Сами файлы лучше хранить на объектном хранилище с публичными HTTPS-адресами и без временных токенов доступа. Это предлагаемый дизайн, не реализованный код.

## 9. Масштабирование

**Пилот:** 6–10 историй из разных жанров с обязательной ручной озвучкой хотя бы части, измерение обнаружимости через Алису.

**Первая серия:** ещё 20 только после технически успешного пилота и положительных слушательских проб.

**Плановые волны:** около 20 выпусков в месяц при достаточном числе редакторов и дикторов. 120 эпизодов — около шести месяцев такого темпа, без учёта работы над пилотом и организационных задержек. Это производственная гипотеза, не гарантированный график.

**Готовность к 150:** добавить 30 историй только из направлений, которые действительно востребованы детьми; не увеличивать количество ценой однообразия.

## 10. Что считать успехом

Не «в Яндекс Музыке опубликовано 120 файлов», а:

- ребёнок может сам попросить понятную татароязычную сказку;
- Алиса правильно её запускает в детском режиме;
- ребёнок дослушивает, возвращается и просит продолжения;
- эмоциональные жанры представлены шире фольклорных и назидательных историй;
- у редакции есть повторяемый процесс выпуска новых произведений.
